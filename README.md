# XDownloader

Android 优先的 Flutter Material 3 视频下载工具。从 X / Twitter 帖子链接解析视频，保存到设备的公共下载目录。

- 系统后台下载、多清晰度选择、封面与应用内播放器。
- 内置 11 个解析来源，含 TWDown.net、TweetDL、TwSaver、TWMate。可调整备用源优先级，近期失败源短暂跳过；检测可验证视频响应。
- 网络或失效链接的失败任务可从原帖重新解析后重试，尽量保留原视频、画质与文件名；等待中可取消。
- 应用设置支持左右手模式，操作按钮随之调整，底部导航顺序保持原样。
- 封面持久缓存配合有上限的内存缓存，支持容量调整、查看及清理。
- 全屏、倍速、双击暂停、进度／亮度／音量手势。
- 下载页长按收藏原帖；收藏支持排序、重命名、横滑分类、多选筛选与批量取消／撤回。长按分类可改名或删除，删除分类保留收藏链接。
- 收藏、下载和下载历史支持本地关键词搜索，可与分类／状态筛选组合；全选仅选择当前结果，隐私模式会清空搜索。
- 文件命名支持原始标题，或点选标题、作者、日期等标签组合规则；支持横向拖动排序、自定义分隔符和实时预览。另有下载历史与隐私模式。
- 动态取色、深浅主题、分组设置首页与无描边色块二级页面，白底自适应图标与新版关于页。
- 底部链接输入栏、粘贴后自动解析、灰度半透明空状态图案，已收藏链接使用红心；底部操作随页面滑动，保持内容位置稳定。
- 链接收起时单行渐隐，编辑时展开；解析源支持单个或多选导入、导出。
- 隐私模式支持可选4–6位数字PIN，首页空白内容区域连续三击解锁；键盘按屏幕比例调整，输入后点击确认。
- GitHub Releases 应用内更新，支持稳定版和 Beta 渠道，后台下载校验完成后提示安装。
- 启动新版弹窗可直接下载或关闭提醒，手动检查始终显示结果；更新说明使用 Markdown 排版，关于页可离线查看更新日志，使用说明可直接跳转相关页面。
- 关于页头像可点击互动，每六次切换头像并与主页同步，重启保留头像选择。

## 安装与更新

从 [Releases](https://github.com/ThermalEX/XDownloader/releases) 下载 APK。多数当前 Android 手机选择 `arm64-v8a`；无法确认架构时选择不带架构后缀的通用包。首次安装需要允许浏览器安装应用。

安装后进入 **设置 → 应用更新** 选择渠道和检查新版。应用会校验安装包，然后交由 Android 确认安装；首次需要允许 XDownloader 安装更新。切回稳定版不会自动降级，请等待版本号更高的正式发布。

更新使用相同包名和签名，保留本地数据。自行编译的不同签名 APK 不能覆盖官方发布版本。

## 开发

源码位于 `client/`，参见 [构建说明](BUILDING.md) 和 [贡献指南](AGENTS.md)。公开 Git 历史从经过审查的源码基线开始；私人设备截图、日志、签名文件不包含在内。历代原始 APK 可在 Releases 下载；历史归档标签不代表对应旧版源码快照。

隐私模式只限制应用内显示与操作，不加密公共目录视频。解析源可能受网络与上游服务变化影响。请仅下载和使用你有权保存的内容。
