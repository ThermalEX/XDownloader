# XDownloader 2.14.0

- **隐私解锁**：支持可选的4–6位数字 PIN，使用全屏数字键盘，输入几个数字显示几个圆点，点击确认后验证。首页空白隐私提示处连续三击可进入解锁；无密码时直接退出隐私模式。
- **隐私模式**：首页解析源旁可一键开启，开启后入口隐藏；保留输入、粘贴、分享解析和下载，继续隐藏收藏、下载历史及敏感信息。已有解析在开启时清空，新解析不会因修改其他设置而消失。
- **收藏详情**：爱心移到三点菜单右侧，封面不再被遮住，列表中间只显示名称；菜单新增详情，名称、链接和作者各一行，点击可复制完整值。后续解析可补充作者，保留自定名称和分类。
- **悬浮操作**：首页输入栏和收藏页底部按钮悬浮在内容上，从操作行中部开始渐隐，末项仍可完整滚动查看。
- **界面对齐**：收藏撤回提示6秒后自动消失；封面缓存条目统一宽高、边距和文字渐隐。解锁页左侧退格、右侧确认使用同色柔和背景。

ARM64 包适合多数当前手机；通用包兼容更多架构。沿用原签名，可保留数据覆盖升级。

验证：337 项离线测试、静态分析及正式包检查通过。界面迭代交由用户在 TEST 模拟器手动测试，本版未进行真机或生产应用内升级验收。

## XDownloader 2.13.0

- **缓存管理**：在“下载与存储 → 封面缓存”查看占用和封面、清理缓存，并自定义 0–2048 MB 上限，默认 100 MB。清理保留视频、收藏及下载记录。
- **关于页**：信息条目高度统一，长文字末尾渐隐。点击技术栈查看完整文字，弹窗随主题显示半透明遮罩，点空白即可关闭。
- **更新体验**：并行检查更新清单，减少等待；下载时“取消下载”和“后台继续”同排显示，收起窗口后继续下载。

ARM64 包适合多数当前手机；通用包兼容更多架构。沿用原签名，可保留数据覆盖升级。

验证：294 项离线测试、静态分析和正式构建检查通过。仅核对指定 TEST 模拟器启动；新增功能由用户自行测试，本版未进行真机或生产自升级验收。

## XDownloader 2.12.0

- **本地搜索**：收藏、下载和下载历史可按标题、文件名、原帖链接或帖子编号搜索，支持多个关键词，并与分类或历史状态筛选组合；全选仅作用于当前结果。搜索不上传、不保存，开启隐私模式会清空。
- **列表效率**：复用收藏排序结果，去掉重复监听和筛选；下载条目按需创建，减少进度刷新时的构建开销。
- **分类滑动**：修复页面尚未完全切换到收藏时，滑动分类栏带动整个页面的问题。
- **头像彩蛋**：点击关于页头像会抖动并随机出现漫画气团、青筋或爱心等装饰；每六次切换头像，第六次立即使用新效果，主页同步并保留头像选择。空状态图案保持透明灰度效果。

ARM64 包适合多数当前手机；通用包兼容更多架构。沿用原签名，可保留数据覆盖升级。

验证：267 项离线测试、静态分析通过。本轮 TEST 模拟器未能启动，新增改动未进行设备验收；未操作真机或 MAA 实例。

## XDownloader 2.11.0

- **分类管理**：长按收藏页上方的分类，可改名或删除。删除分类会将收藏移到未分类，保留链接。
- **批量收藏操作**：长按进入多选，支持全选、批量取消收藏和撤回。
- **命名规则**：点选标题、作者、日期等标签添加到规则，长按左右拖动排序，支持自定义分隔符和实时预览。
- **界面优化**：修正动态取色下背景分区重合的问题；消息默认显示在导航栏上方，键盘出现时移到键盘上方；键盘收起时导航栏平滑返回。
- **更新与日志**：更新弹窗加宽，不再提醒与发布页入口同排；版本说明支持 Markdown 排版，关于页新增离线更新日志。

## XDownloader 2.10.0

- **下载与收藏**：长按已下载视频，可将原帖链接单个或批量加入收藏。重复添加会保留已有名称和分类。
- **分类导航**：收藏页支持创建分类、横向滑动和多选筛选。
- **首页**：增加主题单色图案和空状态提示，粘贴链接后直接解析，每档分辨率使用独立圆角色块。
- **应用更新**：检查更新与发布页入口放在同一区域；使用说明增加相关设置与页面跳转。
