# XDownloader 2.11.0

- **分类管理**：长按收藏页上方的分类，可改名或删除。删除分类会将收藏移到未分类，保留链接。
- **批量收藏操作**：长按进入多选，支持全选、批量取消收藏和撤回。
- **命名规则**：点选标题、作者、日期等标签添加到规则，长按左右拖动排序，支持自定义分隔符和实时预览。
- **界面优化**：修正动态取色下背景分区重合的问题；消息默认显示在导航栏上方，键盘出现时移到键盘上方；键盘收起时导航栏平滑返回。
- **更新与日志**：更新弹窗加宽，不再提醒与发布页入口同排；版本说明支持 Markdown 排版，关于页新增离线更新日志。

## XDownloader 2.10.0

- **下载与收藏**：长按已下载视频，可将原帖链接单个或批量加入收藏。重复添加会保留已有名称和分类。
- **分类导航**：收藏页支持创建分类、横向滑动和多选筛选。
- **首页**：增加主题单色图案和空状态提示，粘贴链接后直接解析，每档分辨率使用独立圆角色块。
- **应用更新**：检查更新与发布页入口放在同一区域；使用说明增加相关设置与页面跳转。
